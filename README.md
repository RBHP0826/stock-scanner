# 🚀 Premium Stock Selection & Monitoring Dashboard

이 프로젝트는 실시간 주식/암호화폐 검색, 매매법별 기술적 분석 지표 산출, 그리고 주도주 테마 분석 일지(쉐도잉 일지)를 기록할 수 있는 프리미엄 Streamlit 대시보드 애플리케이션입니다.

---

## ✨ 주요 제공 기능

1. **실시간 주종목 스캐너 (Stock Scanner)**
   - 한국 시장(KRX), 미국 시장(US), 암호화폐(Upbit) 상위 종목의 가격 및 거래량 데이터를 실시간으로 가져옵니다.
   - 단테, 고작, 퓨처온 등 다양한 전문가 매매 전략의 점수를 실시간으로 계산해 필터링합니다.
   - **[개선] 실시간 스캔 진행률(Progress Bar)**: 스레드 풀 구동 시 현재 분석 중인 종목명과 작업 진행 현황(%)이 UI에 실시간 표시됩니다.
   - **[개선] 스캔 진단 통계 리포트**: 스캔 종료 후 총 대상, 성공률, 실패 건수, 조건 만족 개수를 4대 지표 카드로 명확하게 브리핑합니다.
   
2. **이중 대체 데이터 수집 (Fallback API)**
   - FinanceDataReader(FDR) 수집 장애 시, 한국 시장은 `pykrx`, 미국 시장은 `yfinance` 자체 API로 데이터를 우회 수집하도록 이중 보호막을 탑재하여 스캔 안정성을 대폭 향상시켰습니다.

3. **종목명 자동 변환 및 포트폴리오 세척**
   - 검색 및 포트폴리오 수동 등록 시 코드(예: `005930`)가 아닌 한글 종목명("삼성전자", "후성")을 입력해도, 검색 엔진을 통해 자동으로 올바른 Ticker 코드를 판별하여 분석 및 저장합니다.
   - 최초 구동 시 포트폴리오 데이터(`portfolio.json`)에 한글 명칭이 남아있다면 정밀 마이그레이션(중복 제거 포함)을 자동 수행합니다.

4. **주도주 쉐도잉 일지 & 테마 백과사전**
   - 그날의 급등 테마, 주도 종목, 급등 사유 및 뉴스를 캘린더 형태와 결합하여 히스토리로 관리하고 수동/자동 기록을 지원합니다.

## ⚙️ 설치 및 개발 환경 구축

### 1. 요구 사항
- Python 3.8 이상 (Windows 환경 최적화)

### 2. 패키지 설치
프로젝트 루트 폴더에서 아래 명령어를 통해 필요한 의존성 라이브러리를 설치합니다.
```bash
pip install -r requirements.txt
```

---

## 🏃 실행 방법

Windows 환경에서 대시보드 서버 실행, 브라우저 오픈, 외부 접속용 보안 터널링을 동시에 시작하려면 다음 원클릭 실행기를 실행하십시오.
```bash
python 주식_종목선정_실행기.py
```

- **로컬 접속 주소**: `http://localhost:8501`
- **모바일/태블릿 접속**: 콘솔 창에 출력되는 로컬 IP 주소(`http://[Local-IP]:8501`) 혹은 사이드바의 QR 코드를 활용해 동일 Wi-Fi 망 내에서 접속할 수 있습니다.
- **초기 로그인 비밀번호**: `admin1234` (환경설정 탭에서 변경 가능)

## 🔐 보안 및 환경 파일 관리 (.gitignore)

이 프로젝트는 깃허브(GitHub) 등 공용 저장소에 민감한 개인 정보 및 설정이 유출되는 것을 차단하기 위해 **`.gitignore`** 설정이 적용되어 있습니다.

- **`config.json`**: 텔레그램 봇 토큰(Telegram Token), 채팅 ID, 관리자 비밀번호 등이 로컬에만 저장되고 커밋 대상에서 자동으로 배제됩니다.
- **`portfolio.json`**: 개인이 추가한 관심 종목 포트폴리오 정보가 제외됩니다.
- **`*.log`**: 데이터 수집 에러 로그 및 시스템 작동 로그가 배제됩니다.

GitHub에 올리기 전에 저장소를 새로 구성하시려면, 루트 폴더에서 `.gitignore` 파일이 올바르게 존재하는지 확인하고 푸시하시기 바랍니다.
